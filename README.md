# WebScrapping-CDP

## Descrição

Este projeto tem como objetivo realizar a coleta automatizada de dados (web scraping) de CDP (Curva de Declínio de Produção ou sistema equivalente) em nível de poço, permitindo a extração, organização e análise de informações de produção em ambientes de petróleo e gás.

A aplicação é projetada para acessar fontes web, coletar dados relevantes de produção por poço e disponibilizá-los em formato estruturado para posterior análise, visualização ou integração com outros sistemas.
